# Скрипт оператора — бюджетная линия П5 и П6

Пошаговый скрипт для операторов колл-центра «Жемчужина» (Костанай): поликлиники №5 и №6, бюджетная линия.

Оператор видит только текущий шаг. Он читает фразу пациенту, выбирает ответ, и скрипт переходит к нужному шагу. После выбора П5 или П6 показывается информация только этой поликлиники. Кнопка «Новый звонок» возвращает в начало.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | **Весь текст скрипта**: шаги, фразы, подсказки, справочник врачей, нестандартные ситуации, памятка. Почти все правки — здесь. |
| `app.js` | Логика переходов, кнопки, поиск. Трогать не нужно. |
| `admin.html`, `serialize.js` | Редактор для руководителя. |
| `style.css` | Оформление. |
| `index.html` | Каркас страницы. |

## Как поменять скрипт

Откройте редактор: **https://astr-debug.github.io/medic/admin.html**

- **Шаги скрипта** — фразы пациенту, подсказки оператору, кнопки «что дальше». Отдельные поля для П5 и П6. Справа предпросмотр: так шаг увидит оператор.
- **Врачи П5 / Врачи П6** — заголовки, текст и таблицы вкладки «Врачи».
- **Нестандартное** — ситуации и что делать.
- **Памятка** — общие правила.

Кнопка **Сохранить на сайт** записывает изменения в этот репозиторий, операторы увидят их через 1–2 минуты. Для сохранения нужен ключ доступа GitHub (кнопка «Доступ GitHub» — там пошаговая инструкция). Без ключа можно редактировать и скачать `data.js`.

Перед сохранением редактор проверяет, что все кнопки ведут на существующие шаги. Незаконченные правки хранятся в браузере как черновик.

## Как открыть локально

Скачайте репозиторий и откройте `index.html` в браузере. Сервер не нужен.

## Конфиденциальность

В репозиторий не кладём пароли, доступы к РПН, данные пациентов и VIP-списки.
