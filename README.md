# Скрипт оператора — бюджетная линия П5 и П6

Пошаговый скрипт для операторов колл-центра «Жемчужина» (Костанай): поликлиники №5 и №6, бюджетная линия.

Оператор видит только текущий шаг. Он читает фразу пациенту, выбирает ответ, и скрипт переходит к нужному шагу. После выбора П5 или П6 показывается информация только этой поликлиники. Кнопка «Новый звонок» возвращает в начало.

## Файлы

| Файл | Что внутри |
|---|---|
| `data.js` | **Весь текст скрипта**: шаги, фразы, подсказки, справочник врачей, нестандартные ситуации, памятка. Почти все правки — здесь. |
| `app.js` | Логика переходов, кнопки, поиск. Трогать не нужно. |
| `style.css` | Оформление. |
| `index.html` | Каркас страницы. |

## Как поменять скрипт

Откройте `data.js` на GitHub → значок карандаша → правка → **Commit changes**. Через минуту сайт обновится.

Шаг устроен так:

```js
filtGo:{t:"Направить в фильтр", kick:"Фильтр",
  say:{p5:"Фраза для П5…", p6:"Фраза для П6…"},   // что сказать пациенту
  note:"Подсказка оператору",                      // строка = для всех
  opts:[["Дальше","close"]]},                      // кнопки: [надпись, id следующего шага]
```

- `say` и `note` могут быть строкой (одинаково для П5 и П6) или объектом `{a: общее, p5: …, p6: …}`.
- Кнопка: `["Надпись", "idШага"]`. Можно добавить третий элемент: `{only:"p5"}` — кнопка только на П5; `{line:"p6"}` — кнопка выбирает линию П6; `{sub:"пояснение"}` — мелкий текст под надписью.
- `[в квадратных скобках]` — то, что оператор подставляет сам; на странице подсвечивается.
- Новая строка внутри текста — `\n`.

## Как открыть локально

Скачайте репозиторий и откройте `index.html` в браузере. Сервер не нужен.

## Конфиденциальность

В репозиторий не кладём пароли, доступы к РПН, данные пациентов и VIP-списки.
